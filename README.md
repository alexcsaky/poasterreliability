# X release-forecaster tracker (pilot)

A public, checkable record of which X accounts forecast AI model releases correctly, which get them wrong, and
which avoid saying anything checkable. Version 1 covers release claims: timing and attributes (name, price,
specs, benchmark figures).

Private until Alex decides to publish. Start with `AGENTS.md` (brief, layout, commands), then `RULES.md`
(how claims are resolved), `docs/DECISIONS.md` (every design choice) and `docs/STATUS.md` (where things stand).
